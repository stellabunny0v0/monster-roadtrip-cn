# 《Monster Roadtrip》简体中文本地化风格指南

## 目标语气

译文应像一群熟人边公路旅行边互相吐槽。优先保证笑点、节奏和人物口吻，避免逐词对应。
短句可以更短，脏话和性暗示可以保留原作强度；不要把口语改成说明书语气。

## 工作方式

按完整事件块翻译和审校，同一个 `event_id` 中的对白必须一起处理。先读清人物、关系、
前一句铺垫和最后一句笑点，再决定双关、梗和文化参照如何改写。译文状态依次使用
`machine`、`draft`、`reviewed`、`ingame-ok`；只有实机确认过文字框、变量和节奏后才标记
`ingame-ok`。

## 人物口吻

- **Polly / 波莉**：派对幽灵，俏皮、随性、直白，常带脏话、酒精、毒品和性暗示。
  `boo` 按关系译作“宝”“小可爱”或直接省略；`vibe` 常译作“兴致”“气氛”“感觉”，
  不固定成一个词。
- **Scott / 斯科特**：热情、单纯、兄弟感强。句式直接，多用“兄弟”“好耶”“开干”。
- **Damien / 达米恩**：暴躁、好斗、戏剧化。保留粗口和夸张感。
- **Vera / 维拉**：冷静、尖刻、精于算计。少用卖萌语气。
- **Liam / 利亚姆**：自命不凡、文艺腔、故意绕。可以用一本正经的复杂措辞制造笑点。
- **Calculester / 卡库莱斯特**：礼貌、精确、机器式陈述。术语可以严谨，但句子仍需自然。

## 常用术语

| 英文 | 显示译名 | 说明 |
|---|---|---|
| Hype | 热度 | `STA_HYPE` 的数据值必须保留 `Hype`，否则事件解析失败 |
| Magic | 魔力 | `STA_MAGIC` 的数据值必须保留 `Magic` |
| Mind | 头脑 | `STA_MIND` 的数据值必须保留 `Mind` |
| Money | 金钱 | `STA_MONEY` 的数据值必须保留 `Money` |
| Soul | 灵魂 | `STA_SOUL` 的数据值必须保留 `Soul` |
| Stamina | 体力 | `STA_STAMINA` 的数据值必须保留 `Stamina` |
| loading | 加载中…… | 不按动词 `love` 的含义处理 |
| on / off | 开启 / 关闭 | 用于设置开关 |
| turn someone off | 让人下头 / 让人没感觉 | 结合性暗示和上下文处理 |
| chill | 放松 / 歇会儿 / 安静待着 | 不译成“寒冷” |
| vibe | 兴致 / 气氛 / 感觉 | 根据动作和笑点选词 |

## 技术限制

必须原样保留 `%CURRENTPLAYERNAME%`、`%HESHE%`、`[0]`、`[n]` 和富文本标签。
事件 TSV 只允许修改第四列正文；角色、表情、条件、音效等控制列不能改变。
六项 `STA_*` 值同时承担解析器标识作用，当前版本必须保留英文。

任何版本在安装前都必须通过 `validate_translation.py` 和
`validate_runtime_contracts.py`。实机日志中出现 `FAILURE LOADING EVENTS` 时，构建不得发布。
