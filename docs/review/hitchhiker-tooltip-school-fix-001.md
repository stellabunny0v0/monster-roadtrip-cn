# v0.3.8：搭车客增益提示与学校名称

日期：2026-11-19。用户报告右上角搭车客图标的黑色说明框没有文字，以及李姆约会对白将学校译为“惊悚学院”。

## 增益说明空白

只读核对当前游戏资源和代码：

- `level4` 中的两个 `StatsBoxItemTooltip`（6439、7786）分别引用 UILabel 7045、7651。两个 `TooltipLabel` 都只有 Transform 和 UILabel，没有 `LocalizedNGUIFont`，因此没有经过插件已有的字体替换。
- 两个标签使用 `sharedassets3.assets` 中的 UIFont 172：位图字体仅含 308 个字形，最高码点为 710，没有中文，也没有替代字体或动态字体。
- 李姆的 `TOO_PSN_LIAM` 译文“每回合，头脑增加，热度减少。”存在且非空；“每回合头脑增加热度减少”的所有中文字都不在旧字体中。
- `StatsBoxItemTooltip.Show` 通过 TextManager 取译文，直接写入 `uiLabel.text`。原有插件只覆盖带本地化组件的标签，漏掉了这两个控件。

修复在 `StatsBoxItemTooltip.Show` 前为 `uiLabel` 设置已加载的游戏中文字体。使用 `trueTypeFont` 属性触发旧字体解绑和文字几何缓存刷新，避免重复悬停且文本未变化时仍复用空白缓存。Prefix 返回 void，原 Show 方法继续执行；不改说明键、提示开关、显示条件、乘客增益或属性结算。
