# 镜屋鸟名核对（第 150 批）

仅用于 `english_events_maingame:L10645–L10649` 的五个鸟名，不增加人工审校覆盖，不据此讨论法规或保护等级。

- Lilac-breasted Roller → 紫胸佛法僧：[Cornell BirdNET 分类表 Common Names 的 zh-CN](https://birdnet.cornell.edu/taxonomy/species/Coracias%20caudatus)。不采用页面转载的百科描述作证据。
- Bengal Florican → 孟加拉鸨：英文／学名对应见 [IUCN 物种记录](https://doi.org/10.2305%2FIUCN.UK.2018-2.RLTS.T22692015A130184896.en)；中文／学名对应见 [商务部名录](https://policy.mofcom.gov.cn/pact/pactContent.shtml?id=1981)，亦见 [Avibase 分类记录](https://avibase.bsc-eoc.org/species.jsp?avibaseid=4E2CA7F73638A3FB&lang=EN)。
- Nicobar Pigeon → 绿蓑鸠：英文／学名对应见 [Cornell Birds of the World](https://www.birdsoftheworld.com/bow/species/nicpig1/cur/)；中文／学名对应见 [台湾农业主管部门名录](https://www.moa.gov.tw/files/communique/coa_webuser1_20090304111305/0981700180.pdf)，内列“尼可巴鳩（綠蓑鳩）”。
- Galah → 粉红凤头鹦鹉：[Cornell BirdNET 分类表 Common Names 的 zh-CN](https://birdnet.cornell.edu/taxonomy/species/Eolophus%20roseicapilla)。
- Lady Amherst's Pheasant → 白腹锦鸡：[Cornell eBird 物种页](https://ebird.org/species/laaphe1?siteLanguage=zh)，与学名 Chrysolophus amherstiae 对应。

不把物种名误译为“乳油卷饼”“阿默斯特夫人的野鸡”。
