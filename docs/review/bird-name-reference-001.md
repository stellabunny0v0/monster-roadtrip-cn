# 第 115 批鸟名核对

仅为鸟名／用词核对，不增加人工审校覆盖。游戏中并非每个词都是精确物种名，保留原来的类别混列和最后虚构“蓝鹰”的包袱，不把它改成科学清单。

- Bushtit → 丛山雀：[Cornell BirdNET 中文名](https://birdnet.cornell.edu/taxonomy/species/Psaltriparus%20minimus)。只核对 Common Names，不引用其二手描述段落。
- American Black Duck → 北美黑鸭：[Cornell BirdNET 中文名](https://birdnet.cornell.edu/taxonomy/species/Anas%20rubripes)。
- Falcated Duck → 罗纹鸭：[横琴政府转载名录](https://www.hengqin.gov.cn/lab/flfg/bmgz/content/post_3725922.html) 中旧属名 Anas falcata；现属名 Mareca falcata 见 [eBird 物种页](https://ebird.org/species/falduc?siteLanguage=zh)。
- Fulvous Whistling-Duck → 草黄树鸭：英文／学名对应见 [eBird](https://ebird.org/species/fuwduc?siteLanguage=en_ZA)，中文／学名对应见 [商务部名录](https://policy.mofcom.gov.cn/pact/pactContent.shtml?id=1981)。仅用于译名核对，不引用或讨论法规效力。

`L2956` 将 bushtit / bullshit 的口误改为“鸟话——我是说，屁话”，保留念鸟名后的笑点。
