# 第 137 批生僻词核对

适用条目：`english_events_maingame:L7870`。

- 原文 pteronphiliac 对应羽毛挠痒的偏好，译为“羽毛挠痒控”，移除旧译凭空引入的“恋童癖”。它不是原文所说的人群或概念。
- 来源：Lucky Tomaszek 的本人署名问答，2019-03-29，栏目中直接解释 pteronphilia 与羽毛挠痒的关联：[MKE SEX: Quickies, pt. 4](https://milwaukeerecord.com/city-life/mke-sex-quickies-pt-4-kinky-quickies/)。用于核对游戏措辞，不据此作临床分类或诊断。
- Douhini 为小众俚语：保留 Douhini，并用“腋下挠痒法”帮助理解。可追溯的原始用户词条为 Noah Berube，2007-09-07：[Urban Dictionary 的 Douhini 定义](https://www.urbandictionary.com/define.php?term=Douh)。这里只支持用词含义，未将社区造词称作正式医学术语。
- 同批 BDE 按“巨屌气场”处理，和莫蒂按字面理解成器官大小的回复区分。未把 BDE 当化学缩写。

原文中的同意、界限、安全词“五个屁股”和“木瓜”均保留；未另写操作指南。
