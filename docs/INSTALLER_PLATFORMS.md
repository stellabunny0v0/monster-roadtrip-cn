# 安装器与平台范围

2026-10-31。

Windows 首版采用完整离线 ZIP：双击 `install.bat`，由系统自带 Windows PowerShell 5.1 执行安装；`uninstall.bat` 使用同一份安装记录卸载。安装时不下载／执行第三方网络内容，不改变系统执行策略，不自动提权，不改游戏原有二进制与 UserData。

安全性来自路径和版本检查、文件哈希、覆盖前备份、有限的写入范围、失败回滚及卸载时的改动保护。把脚本封装为 EXE 本身不会提高这些能力；未签名 EXE 还可能增加系统提示。若以后使用 Inno Setup 等工具制作 EXE，应继续复用这些检查，并单独处理签名、发布和验证。

## 当前验证

| 范围 | 状态 |
| --- | --- |
| Windows 11 本机游戏 | 隔离副本正常汉化和退出，设置返回 UI 完整 |
| Windows 自带 PowerShell 5.1 | 12 项安装器集成测试通过 |
| Windows 10 Intel／AMD | 设计目标，尚待独立实机验证 |
| Windows ARM、Windows 7／8 | 不宣称适配；当前自动安装拒绝旧版系统和 ARM |
| 其他游戏构建 | 通过已测试二进制 SHA256 限定，未匹配则停止安装 |
| 游戏安装路径含中文 | 当前 Mono 路径转换错误已复现，暂不自动安装；包的解压路径可以中文 |
| Steam 正常登录下的完整流程 | 仍需用户正常游玩确认；本次隔离退出对照未连接 Steam |

安装器测试覆盖只读预检、未知加载器／损坏包／越界路径／不同游戏版本拒绝、新安装、重复安装不写入、卸载预检和卸载、已有加载器及其他 Mod／配置保留、用户修改文件保护。测试用游戏文件副本和虚构存档；原游戏未因安装器测试而读写。安装失败回滚有实现，但未把所有磁盘故障和掉电情形宣称为已测试。

当前升级策略保守：完整相同版本直接报告已安装；有其他版本的安装记录时，提示先用旧包卸载，再安装新包。已有手动安装的本汉化会先备份旧文件；卸载一键包时删除汉化插件，保留安装前就存在的共享 BepInEx 和退出兼容补丁，备份不自动覆盖回当前存档。

## Mac 实验包

Mac 使用独立的 BepInEx macOS 加载器、`install.command`／`uninstall.command` 和启动脚本，不包含 Windows 的 `winhttp.dll` 或 `.bat`。安装步骤见 [MACOS.md](MACOS.md)。发布为独立 prerelease，不替换 Windows 稳定版。

| 范围 | 状态 |
| --- | --- |
| x86_64 Mono 游戏进程 | 实验目标；安装前检查 Mach-O、Mono 程序集及必需接口名称，尚无真实 Mac 游戏文件验证 |
| Apple Silicon | 仅通过 Rosetta 运行 x86_64；启动脚本明确选择该架构，尚待真机验证 |
| 纯 arm64、32 位、IL2CPP | 自动安装拒绝 |
| 安装与卸载的文件操作 | Windows Git Bash 隔离夹具验证；macOS 系统接口使用模拟，不能视为 Mac 验证 |
| ZIP 脚本权限与换行 | 明确设置 Unix 0755、LF，校验包内清单与 SHA256 |
| 存档路径 | 根据游戏反编译路径与 Unity dataPath 定义实现；安装器备份四类候选位置，插件启动备份从实际 dataPath 推导 |
| 中文字体、姓名存取、属性结算、设置返回、退出 | 未做 Mac 实机测试，不声明已通过 |

安装脚本不修改游戏 `.app`、不改 Steam 配置或系统安全策略。只向外层游戏目录写入清单中的加载器、插件和安装记录。存档复制备份后核对哈希；卸载只移除记录且未被修改的文件，有其他 Mod 或先前已有加载器时保留共享部分。插件仅扩展启动备份的来源路径，不改变游戏的存档读写目标。

尚需在 Intel 和 Apple Silicon 的真实游戏上完成完整安装、正常游玩、存档恢复与卸载验证，以及字体和界面检查。没有这些环境前始终保留实验版标识。

当 Windows 10、其他游戏构建或 Mac 测试完成后，更新验证矩阵及清单，再扩大自动安装允许的范围。
